# 架构速学

系统架构设计师考试速学网页，包含知识点、复习、课时和论文四个模块。

## 在线访问

<https://z1948296027.github.io/architect-study/>

## 本地预览

```bash
python3 -m http.server 8080
```

打开 <http://localhost:8080>。

## 部署

这是一个纯静态站点，可以直接部署到 Gitee Pages、GitHub Pages、Cloudflare Pages 或任意静态文件服务器。入口文件为 `index.html`，不需要构建。

## 目录

- `index.html`：页面入口
- `styles.css`：样式
- `app.js`：交互逻辑
- `data.js`、`phase4-data.js`、`phase5-data.js`、`phase6-data.js`：知识点数据
- `essay-data.js`、`essay.js`：论文模块
- `assets/`：封面和本地图标库
